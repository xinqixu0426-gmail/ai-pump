# 线圈领域模型

> 更新于 2026-09-15。本文定义定子组合、绕组方案、计价方式、成本匹配和历史数据迁移规则。

## 1. 业务对象

### 定子组合

定子组合由以下三个标准维度唯一确定：

- `diameterMm`：定子标准直径，整数毫米；
- `material`：`钢带` 或 `冷轧`；
- `slotType`：`小眼` 或 `国标眼`。

`commonName` 是工厂俗称，不参与物理规格判断。当前确认 `12` 表示 `120mm`，数据库同时保存俗称和标准直径。

### 绕组方案

绕组方案归属于一个定子组合，并记录片数、计价方式、默认搭配电缆线径/电容及主副漆包线绕组备忘。方案名称由服务端规格规则生成；纯改名走受保护目录命令，保留 `coilId` 和不可变方案代号。存在目录身份档案时删除转为 `disabled` 并保留关联及审计，无档案的旧方案仍受原库存/流水删除保护。默认搭配电缆的旧“线径”指横截面积mm²，单价按元/米计算。方案状态：

- `official`：正式方案，参与配方、报价和当前成本计算；
- `testing`：测试方案，只用于试验记录，不进入正式成本；
- `disabled`：停用方案，不参与匹配。

同一“定子组合 + 片数”可以有多套正式方案，用于区分不同线重、电压、频率、市场或绕组配置。每套方案以不可变的 `schemeCode` 和数据库 `coilId` 唯一识别，并可记录 `ratedVoltageV/ratedFrequencyHz/market/schemeFamilyCode`。同一组合最多有一套 `isDefault=true` 的正式默认方案；新增其他正式方案不会再把旧方案降为测试。

精确片数的配方和常用配置必须保存具体 `coilId`；没有精确片数而需要插值或外推时，必须保存明确的 `coilSchemeFamilyCode`。规格、片数、材质和槽眼只作为可读快照与历史兼容字段。页面只有一个合法选择时可自动带入；存在多个具体方案或多个方案系列时必须由用户明确选择，不能按记录顺序猜测。

## 2. 成本匹配

每套绕组方案只使用一种计价方式：

- `calculated`：按定子单片成本、片数、铜重、铜价基数、线圈加工费和转子加工费计算；
- `kit`：直接采用供应商整套采购价 `kitPrice`；可选保存 `wireWeight/copperBase` 作为价格参考，但不再计算定子、铜重或加工费。

成本必须在相同 `diameterMm + material + slotType` 内匹配：

1. `coilId/schemeCode` 明确指定时，只使用该正式方案，并校验规格、材质、槽眼和片数一致；
2. 未指定具体方案的兼容调用，在同片数只有一套正式方案时使用该方案；存在多套时仅允许唯一默认方案兜底，没有唯一默认则返回 `COIL_SCHEME_AMBIGUOUS`；
3. 精确命中 `kit` 方案时，成本严格等于 `kitPrice`，返回方案保存的参考线重和铜价基数；参考值及客户指定线重和铜价都不覆盖该价格；
4. 没有同片数时，只在明确的同一 `schemeFamilyCode` 内对 `calculated` 正式方案插值或外推；存在多个方案族且调用方未指定时返回 `COIL_SCHEME_FAMILY_REQUIRED`，`kit` 方案不参与；
5. 不跨材质、不跨槽眼、不使用测试或停用方案；
6. 精确片数的配方保存 `coilId`，非精确片数保存 `coilSchemeFamilyCode`，并共同保存规格快照、`pricingMode`、`kitPrice` 和最终成本快照；报价和订单沿用已保存的选择，精确方案的采购参考价及库存沿用具体方案身份。

## 3. 历史迁移

| 历史值 | 标准直径 | 材质 | 槽眼 |
|---|---:|---|---|
| `12 / 钢带` | 120 | 钢带 | 小眼 |
| `90 / 钢带` | 90 | 钢带 | 小眼 |
| `12 / 冷轧国标眼` | 120 | 冷轧 | 国标眼 |

历史配方和常用配置没有槽眼字段时按 `小眼` 兼容。历史 `spec=12` 保持不变，通过 `diameterMm=120` 建立标准关联，避免破坏已有配方快照。迁移 70 为既有正式方案回填唯一默认、稳定方案编码和历史方案族，并在能够唯一匹配时为配方/常用配置回填 `coilId`；迁移 71 为非精确片数且只能落入一个历史计算方案族的记录回填 `coilSchemeFamilyCode`，存在精确候选或多个可能系列时保持未绑定并等待人工选择。两次迁移都不改变既有方案状态、成本和库存。

## 4. 验收标准

- 线圈页可独立选择标准直径、俗称、材质和槽眼；
- 钢带与冷轧都可分别建立小眼、国标眼组合；
- 测试方案不会参与配方下拉、成本试算和报价成本；
- 供应商套件价只在规格、材质、槽眼和片数精确匹配时采用；可选参考线重和铜价基数不参与成本，且套件价方案不会随铜价同步或定子组合批量改单片价变化；
- 套件价表单的线重和铜价基数标题明确标注“可选”，列表有正值时展示参考值，未填或为 0 时显示 `-`；
- 配方可选择槽眼和具体正式方案；同一组合只有一套时自动带入，多套时显示名称、电压、频率、市场和线重并要求明确选择；
- 同一组合多套正式方案分别保存、计价、扣库存和生成采购项，不按名称或最新记录合并；
- 非精确片数保存方案系列后可以稳定插值或外推；单条历史配方仍未明确时仅标记该条成本待处理，不再导致整个配方列表为空；
- 编辑旧配方默认恢复为小眼；
- `12` 和 `120` 可以命中同一标准直径的正式方案。
