# 线圈领域模型

> 更新于 2026-08-29。本文定义定子组合、绕组方案、计价方式、成本匹配和历史数据迁移规则。

## 1. 业务对象

### 定子组合

定子组合由以下三个标准维度唯一确定：

- `diameterMm`：定子标准直径，整数毫米；
- `material`：`钢带` 或 `冷轧`；
- `slotType`：`小眼` 或 `国标眼`。

`commonName` 是工厂俗称，不参与物理规格判断。当前确认 `12` 表示 `120mm`，数据库同时保存俗称和标准直径。

### 绕组方案

绕组方案归属于一个定子组合，并记录片数、计价方式、默认搭配电缆线径/电容及主副漆包线绕组备忘。方案状态：

- `official`：正式方案，参与配方、报价和当前成本计算；
- `testing`：测试方案，只用于试验记录，不进入正式成本；
- `disabled`：停用方案，不参与匹配。

同一“定子组合 + 片数”只能有一套正式方案。将测试方案转为正式时，系统自动把原正式方案降为测试。

## 2. 成本匹配

每套绕组方案只使用一种计价方式：

- `calculated`：按定子单片成本、片数、铜重、铜价基数、线圈加工费和转子加工费计算；
- `kit`：直接采用供应商整套采购价 `kitPrice`；可选保存 `wireWeight/copperBase` 作为价格参考，但不再计算定子、铜重或加工费。

成本必须在相同 `diameterMm + material + slotType` 内匹配：

1. 优先使用同片数正式方案；
2. 精确命中 `kit` 方案时，成本严格等于 `kitPrice`，返回方案保存的参考线重和铜价基数；参考值及客户指定线重和铜价都不覆盖该价格；
3. 没有同片数时，只在同一定子组合的 `calculated` 正式方案之间插值或外推，`kit` 方案不参与；
4. 不跨材质、不跨槽眼、不使用测试或停用方案；
5. 配方保存线圈身份、`pricingMode`、`kitPrice` 和最终成本快照，报价、订单、采购参考价及库存继续复用该后端结果。

## 3. 历史迁移

| 历史值 | 标准直径 | 材质 | 槽眼 |
|---|---:|---|---|
| `12 / 钢带` | 120 | 钢带 | 小眼 |
| `90 / 钢带` | 90 | 钢带 | 小眼 |
| `12 / 冷轧国标眼` | 120 | 冷轧 | 国标眼 |

历史配方和常用配置没有槽眼字段时按 `小眼` 兼容。历史 `spec=12` 保持不变，通过 `diameterMm=120` 建立标准关联，避免破坏已有配方快照。

## 4. 验收标准

- 线圈页可独立选择标准直径、俗称、材质和槽眼；
- 钢带与冷轧都可分别建立小眼、国标眼组合；
- 测试方案不会参与配方下拉、成本试算和报价成本；
- 供应商套件价只在规格、材质、槽眼和片数精确匹配时采用；可选参考线重和铜价基数不参与成本，且套件价方案不会随铜价同步或定子组合批量改单片价变化；
- 套件价表单的线重和铜价基数标题明确标注“可选”，列表有正值时展示参考值，未填或为 0 时显示 `-`；
- 配方可选择槽眼，并只能看到对应正式方案的片数；
- 编辑旧配方默认恢复为小眼；
- `12` 和 `120` 可以命中同一标准直径的正式方案。
