# 开发待办与向量检索主线

> 更新于 2026-07-29。本文用于记录延期事项和当前开发主线，不代表功能已经上线。完成项应从本文移除，并同步到当前功能、API 和业务流程文档。

## 1. 当前主线：Knowledge V6 向量检索

### 目标

在不改变现有业务事实来源的前提下，为工厂知识增加语义检索能力。用户不必输入数据库中的精确名称，也能找到表达相近的零件、配方、线圈、规则和技术资料。

向量检索只负责“找到可能相关的知识”，不能替代：

- 零件价格、库存、铜价、报价、订单状态等实时业务 API；
- `knowledge_entries` 中可追溯的原始来源关系；
- FTS5 对型号、规格、客户名和合同号等精确词的检索；
- 写操作确认、权限、审计和业务校验。

### 已完成的准备

- 当前正式库有 126 条知识，正文约 2 万字，最大单条约 1600 字。
- Windows 开发环境已验证 `sqlite-vec v0.1.9` 可加载到现有 `better-sqlite3`，并可对普通 BLOB 向量执行余弦距离排序。
- 第一阶段不部署 Qdrant、Milvus、PostgreSQL/pgvector 等独立服务，继续保持单机 SQLite 部署。
- 第一阶段不使用 ANN 虚拟表。向量保存在普通表中并做精确扫描；当前规模足够快，也更容易备份、迁移和回退。
- 推荐嵌入模型为本地 `multilingual-e5-small`，输出 384 维向量。模型支持中文和多语言，不需要把工厂资料发送给新的外部 API。

`sqlite-vec` 当前仍是 pre-v1 组件，因此必须固定版本、保留禁用开关，并在扩展加载失败时自动回退到现有 FTS/LIKE 检索。

### V6.1 向量存储与模型适配

- [ ] 固定 `sqlite-vec` 和本地 embedding 运行时版本。
- [ ] 增加 `knowledge_embeddings` 表，保存 `entryId/model/dimensions/contentHash/embedding/createdAt/updatedAt`。
- [ ] 建立 embedding provider 接口，第一版实现本地 `multilingual-e5-small`。
- [ ] 明确模型缓存目录、首次下载、离线部署和 Mac Mini ARM64 启动检查。
- [ ] 扩展不可用或模型未准备好时保持 FTS 正常可用，不阻塞 API 启动。
- [ ] 增加只读能力检查，返回扩展版本、模型、维度、待生成数量和最近错误。

### V6.2 增量向量同步

- [ ] 以 `knowledge_entries.content_hash` 判断是否需要重新生成向量。
- [ ] 新增和更新知识时生成向量，来源删除时同步删除向量。
- [ ] 模型名称或维度变化时执行可恢复的全量重建，不混用不同模型结果。
- [ ] 向量生成失败不能回滚已经成功的业务数据和文字知识同步。
- [ ] 同步历史记录向量新增、更新、跳过、删除、失败数量和耗时。
- [ ] 模型首次加载和批量生成不能阻塞普通业务请求。

### V6.3 混合检索

- [ ] 同时召回 FTS/BM25 和向量结果，不用向量结果完全覆盖精确匹配。
- [ ] 使用稳定的融合排序；型号、规格、客户名和合同号精确命中优先。
- [ ] 返回 `matchMode/keywordRank/vectorDistance/finalScore`，便于诊断。
- [ ] `entryType/sourceTable` 过滤必须在两条检索链路中保持一致。
- [ ] 查询向量生成失败时自动回退 FTS，不向用户伪装为语义检索成功。
- [ ] AI 继续通过 `search_factory_knowledge` 使用统一结果，不增加第二套知识搜索工具。

### V6.4 评测与上线

- [ ] 建立中文别名、口语、错别字和描述性问题的固定评测集。
- [ ] 覆盖泵壳价格、配方详情、线圈材质与槽眼、成品电缆、测试报告类型等历史高风险问题。
- [ ] 对比 FTS、纯向量和混合检索的 Top 1、Top 3 命中率。
- [ ] 验证 Windows 与 Mac Mini 的安装、重启、数据库备份恢复和模型离线缓存。
- [ ] 在看板展示向量覆盖率和异常，但不增加日常人工同步负担。
- [ ] 先以可关闭功能上线观察，再决定是否默认启用。

### 后续扩容条件

只有当知识切片达到数万条，并且精确扫描经过基准测试确认成为瓶颈时，才评估 `vec0` ANN 索引或独立向量服务。不能仅因“向量数据库更高级”增加部署复杂度。

## 2. 延期待办

以下事项暂不进入当前开发版本：

- [ ] 管理待办首次出现、持续时间、处理消失和再次发生的历史追踪。
- [ ] 管理待办逾期、负责人提醒和跨页面处理闭环。
- [ ] AI 上下文从当前最近 10 条继续扩展。
- [ ] PDF 正文与图纸结构解析。
- [ ] 图片 OCR、图纸视觉识别和多模态问答。
- [ ] 客户报价文件自动解析和结构化导入。
- [ ] Excel 通用表格理解；现有性能测试报告和基础表格提取继续保持当前边界。
- [ ] 大规模文档切片、重排模型和复杂知识关系图谱。
- [ ] 多工厂租户隔离；当前产品继续采用每家工厂独立部署。

## 3. 完成标准

向量检索版本只有同时满足以下条件才可上线：

1. 精确型号、价格和库存查询不能因向量结果降低正确率。
2. 口语和同义表达的 Top 3 命中率明显高于当前 FTS。
3. 每条结果仍能追溯到 `sourceTable + sourceId` 和原业务详情。
4. 扩展、模型或向量同步失败时，现有知识搜索和业务页面仍然可用。
5. 普通测试、知识回归测试、生产构建、数据库一致性和 Mac Mini 发布检查全部通过。
