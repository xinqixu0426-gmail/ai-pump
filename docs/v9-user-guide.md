# V9 文件智能处理使用大纲

V9 的目标是让同一份 PDF、Excel、图片或文本文件只保存一次，并能用于当前 AI 分析、关联业务记录或进入长期知识检索。

## 1. 三种使用结果

| 操作 | 适合场景 | 是否进入知识检索 |
|---|---|---|
| 发给 AI 分析 | 临时读取、提取参数、检查表格或理解图片 | 否 |
| 关联客户、报价或质量反馈 | 保存原始依据，之后从业务页面追溯 | 否 |
| 归档到知识库 | 以后希望 AI 跨会话检索、引用和回答 | 是 |

业务附件和知识入库是两个独立动作。把文件挂到客户或报价下面，不代表 AI 已经长期学习该文件。

## 2. 在 AI 工作台上传

1. 打开 `/ai`，点击输入框旁的附件按钮。
2. 选择 PDF、Excel、CSV、TXT、Markdown、PNG、JPG 或 WebP，单个文件不超过 10MB，每条消息最多 4 个。
3. 输入明确任务，例如“读取这份测试报告，列出实测扬程、流量和异常项”或“分析这份客户报价，匹配现有客户和配方”。
4. 只用于当前判断时，不需要归档。
5. 需要以后查找时，点击附件卡片的归档按钮，选择真实客户、报价、配方、质量问题或知识库；正式归档前系统会再次确认。

AI 不会根据上传文件自动新增客户、配方、报价，也不会直接覆盖现有技术参数。

## 3. 从业务页面上传

- 客户：打开 `/customers`，选择客户，在“客户附件”上传客户资料、图片或往来文件。
- 报价：打开 `/quotations`，查看某张报价，在“报价附件”保存客户原始报价、价格表和补充说明。
- 配方：在配方技术档案继续上传性能测试报告；聊天中的其他技术文件也可归档到具体配方。
- 配方检查问题：打开管理看板“数据质量”，在“质量证据附件”选择具体反馈，上传检测照片、测试表或说明。
- AI 回答问题：打开管理看板“知识库”，在待处理的 AI 回答反馈中展开“附件”，上传截图或原始证据。

附件列表支持下载原件和解除关联。解除关联不会删除原文件，也不会删除客户、报价或质量反馈。

## 4. 文件读取能力

- Excel/CSV：保留工作表、行列、单元格、公式和原始位置，可生成只读报价映射草稿。
- 文字型 PDF：按页提取文字和表格，回答可追溯到页码。
- 图片和扫描 PDF：使用本地中英文 OCR，保留页码、文字框和置信度。
- DeepSeek：读取解析文字和 OCR 结果，不直接看图片二进制。
- Kimi 多模态模型：配置有效的 Kimi 开放平台 API Key 且模型支持图片时，可同时接收原图。

OCR 和图纸参数提取只生成候选。低置信度结果必须复核，系统不会自动写入配方或技术档案。

## 5. 报价文件

向 AI 询问“分析这份报价”时，系统只会：

1. 读取文件中的客户、产品、数量和文件价格。
2. 对照当前客户和配方做精确匹配。
3. 列出近似、多候选、未找到或金额不一致项。
4. 全部精确匹配后生成标准报价草稿输入。

文件价格不等于系统成本，正式报价仍由当前配方成本接口重算并由用户确认保存。

## 6. 建议试用顺序

1. 上传一份已知内容的 Excel，询问指定单元格或产品数量，核对原始位置。
2. 上传一份文字型 PDF，询问某页的明确参数。
3. 上传一张清晰图片和一张较模糊图片，确认低置信度结果会提示复核。
4. 把同一文件分别关联到一个客户和一张报价，确认两个页面都能看到并下载。
5. 解除其中一个关联，确认另一个关联仍保留。
6. 把文件归档到知识库，换一个新会话检索文件中的独特关键词。
7. 对一条错误 AI 回答报告问题并上传证据，确认知识管理页可以追溯。

完成上述试用后再进入 V10，重点记录“文件没读到、读错位置、关联错对象、知识检索不到”四类问题。
