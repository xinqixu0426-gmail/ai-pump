# 私人 AI 助理：当前实现与使用

> 核对日期：2026-09-07。描述 V1 冻结源码；生产状态以 [发布检查清单](deployment-checklist.md) 为准。历史方案不是当前运行指令。

## 1. 用途与入口

这是工厂主人使用的私人助理。可以组合查询零件、线圈、配方、客户、订单、采购、库存和知识资料，比较正式成本。无需先把问题归入单一业务域。

Windows 本地入口为 `http://localhost:3000/ai`，登录入口为 `/login`，使用现有访问密码。普通访问认证仍保留，没有独立 owner AI 页面。V1 默认助理不执行业务写工具；明确保存个人记忆是独立的非业务数据命令。

## 2. 实际处理链

`聊天请求 → 会话与个人记忆 → 模型选择只读工具 → 参数与标识校验 → 正式 API → 结果与执行证据 → 继续查询或回答`

- Web 聊天与内部 `processAiChat` 经兼容入口 `aiDispatcherV3` 调用 `aiAssistantRuntime`。旧两阶段 planner、V4 实验不参与默认链，也不是回退方案；V5 Candidate 已撤除。
- 目录由能力注册表生成，目前开放 48 项 Query/Preview，允许跨类型、跨业务组合。每轮最多 7 次模型调用、10 次工具提议；工具执行固定 `allowWrite=false`。
- 正式数据与成本由 API/service 负责。模型可以决定先查配方 A、再查 B 或调用 `compare_recipes`，成本差额也须取正式计算结果。
- 参数经工具唯一 schema 校验，标识须有用户输入或正式结果依据。相似名称不能自动替换目标，多候选根据用户选择继续查询；“两个都看”可分别查询。
- 上一轮结果与原问题绑定主体及 `conversationId`，内存会话有效期 15 分钟，最多 200 个。同会话并发请求会拒绝；进程重启后会话引用需重建。实时价格、成本、库存和状态仍需本轮重查。
- 保存的聊天历史与模型上下文不同：对话可持久保存，模型使用最近消息和预算允许的相关结果。列表给模型简要字段与详情入口，原始工具结果继续用于页面明细和执行证据；过大结果、轮次耗尽或接口失败必须明确未完成范围。
- 正式查询明确目标不存在时，模型视图保留目标及负结果并提示结束该目标的重复扩搜；相同已验证负查询不再重复访问 API。预算耗尽仍列出已核实的缺失目标，不把已有结论覆盖成一句通用错误；其他独立问题仍可读取。成功且完整的零结果回执会提示只在 appliedFilters 范围内没有匹配记录，避免重复扩搜；分页未结束、来源未验证或接口失败不作空结果结论。
- 金额检查只采纳有正式执行证据的结果，包括线圈铜价基数；未验证数据、ID 和线重不能充当金额。金额回答无法核对时，可回显 Query/Preview 的正式金额并保留方案身份，查询档案成本明确标为档案成本；正常库存等非金额回答不触发查询金额兜底。配置试算汇总保留 currentTotalCost、正式配置名称和未完全定价提示。
- 成本预览已有总价时，最终回答不能只提原材料单价或“见上文”；遗漏正式总价将回显正式汇总。模型正文中的 DSML/XML 工具协议不作为工具调用或用户答案，最多纠正一次，仍失败则明确停止并保留已核实事实。

源码入口：`api/routes/ai/chat.cjs`、`api/services/aiAssistantRuntime.cjs`、`aiAssistantContext.cjs`、`aiAssistantSession.cjs`。HTTP 字段、错误与回执见 [API 总表](api-reference.md)，通用约束见 [API 契约](api-contract.md)。

## 3. 长期记忆怎么用

可以直接输入：

- `记入长期记忆：我只说规格和片数问成本时，优先查线圈。`
- `列出泵壳零件时，去零件库找泵壳分类，不是模板。这点记入长期记忆`
- 同会话：`把刚才那条改成：多个线圈方案分别列出。`
- 同会话：`删除刚才那条记忆` 或 `撤销刚才记忆修改`。

这些明确命令由服务端识别并调用个人记忆 API，拿到正式回执才显示保存成功；不依赖模型口头承诺。引用、否定、假设例句不能当作保存授权。修改使用条目 ID 和版本检查，支持幂等、软删除、修订和审计。当前加载最多 100 条有效记忆，单条 1–1500 字；记忆是偏好，不是实时价格或业务事实。

回答下方“报告问题/学习正确做法”仍走原纠错候选与审核流程，与个人记忆尚未合并。两条入口的区别及回归操作见 [纠错学习与发布回归](ai-learning-release-gate-guide.md)。自由指代“把刚才那个记住”不算当前可靠支持的保存句式。

## 4. 验证与限制

用户已于 2026-09-07 确认本地人工验收通过。V1 的真实自动化结果只记录在 [发布检查清单](deployment-checklist.md)，不在各文档复制测试数量。

可用问题包括“12-200 成本是多少”“两个都看”“对比配方 A 和配方 B 的当前成本”“这张订单缺什么料，采购和库存分别怎么样”；名称须以实际数据库对象为准。

隔离本地验收使用 `node scripts/verify-personal-assistant-local.cjs --acceptance`，创建数据库副本和临时 API，不是生产验收。不能将工具成功、流正常结束或一次回答正确等同于所有场景通过。

未完成能力及覆盖缺口统一维护在 [技术债清单](technical-debt.md#6-v1-ai-助理后续事项)。历史推演、失败与实施证据见 [档案索引](archive/README.md)，不据此恢复旧框架或改变 V1 边界。
